# 🛒 Amazon Clone

## 🌟 Overview

This is a simple **Amazon Clone** built using **HTML** and **CSS**. The project focuses on replicating Amazon's front-end design to enhance web development skills and gain hands-on experience with responsive layouts.

## 🎯 Features

✅ Fully responsive design. 📱💻🖥️\
✅ Amazon-style navigation bar with search & cart icons. 🛍️🔍\
✅ Product sections arranged in a grid layout. 🏷️\
✅ Footer with multiple useful links. 🔗\
✅ Hover effects and basic animations ✨

## 🛠️ Tech Stack

- **HTML** 🏗️ - Provides the structure and layout of the webpage.
- **CSS** 🎨 - Responsible for styling, animations, and responsiveness.

## 🚀 Installation & Usage

1. **Clone the repository** 📥
   ```sh
   git clone https://github.com/Himanshu25102005/Amazon-Clone.git
   ```
2. **Navigate to the project folder** 📂
   ```sh
   cd Amazon-Clone
   ```
3. **Open the project in your browser** 🌐
   - Open `index.html` directly or use Live Server in VS Code.
